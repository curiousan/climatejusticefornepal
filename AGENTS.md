# Collaboration preferences

- For improvements to this website, begin with brainstorming and discussion with the user.
- Discuss the ideas, options, and scope until the user and assistant agree on the proposed changes.
- Implement changes only after the user gives explicit approval to make the agreed changes. Agreement on an idea alone is not implementation approval.
- Before approval, keep work to discussion and read-only investigation; do not modify the site's code, content, design, configuration, or tests.
- Approval applies to the agreed scope. Discuss additional improvements and obtain explicit approval before implementing them.
- The user explicitly requested that this workflow be saved as project memory. Keep following it in future sessions unless the user changes it.
- The production domain is `climatejusticefornepal.org`.
